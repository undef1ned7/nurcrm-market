# i18n — русский / кыргызский

Контракт UI-строк для веба и Flutter. **RU — source of truth.** KY заполняет переводчик; пока перевода нет, в `ky` копируем русское значение (не ключ, не пустую строку).

Каталоги: `public/locales/{ru,ky}/{ns}.json`.  
Код: `src/shared/config/i18n.ts`, `src/shared/config/locale.ts`.  
Проверка ключей: `npm run i18n:check`.

## Языки

| Код | BCP-47 | Роль |
|-----|--------|------|
| `ru` | `ru-RU` | fallback, тексты продукта |
| `ky` | `ky-KG` | кыргызский (кириллица) |

Не добавлять `en`, пока нет продукта на английском. Детектор браузера нормализуется в `ru`/`ky`.

Часовой пояс бизнеса: `Asia/Bishkek`. Валюта в UI: сом (`common.currencySom`).

## Namespaces

| ns | Когда |
|----|--------|
| `translation` | CRM (касса, склад, клиенты, настройки) |
| `newLanding` | Маркетинг / лендинг. Грузить только на лендинг-роутах (`i18n.loadNamespaces("newLanding")`) |

В CRM preload только `translation`.

## Ключи

Вложенный JSON. В коде: `t("clients.kpi.debt")`.

```
common.*          кнопки, статусы, сом
errors.*          сеть и валидация (добавлять по мере выноса)
settings.*
clients.*
cashier.*         (следующий экран)
warehouse.*
documents.*
pdf.*
```

- Ключ = смысл, не цитата (`common.save`, не `t("Сохранить")`).
- Один смысл — один ключ.
- Интерполяция только `{{name}}` / `{{count}}`.
- Плюралы i18next: `dealsCount_one|_few|_many|_other`. Русский использует все; кыргызский в CLDR — `one`/`other` (достаточно заполнить их, `_few`/`_many` могут совпадать с `_other`).
- Данные API (ФИО, товары, категории) не переводим. Enum → ключ на фронте.

## Переключатель

Настройки → Интерфейс → Язык интерфейса (`LanguageSelect`). Persist: `localStorage.i18nextLng`.  
`<html lang>` обновляется при смене языка.

## Чеклист PR

- [ ] Тот же ключ есть в `ky` (перевод или копия RU)
- [ ] `npm run i18n:check`
- [ ] Не склеивать фразы из кусков (`t(a) + " " + n`)
- [ ] Числа/даты через `formatMoneyAmount` / `formatDate` / `formatInteger`
- [ ] В Flutter-доке для нового Label указать тот же ключ

## Очередь выноса строк

1. common + алерты  
2. касса / оплата / долг / смена  
3. клиенты (KPI уже на ключах)  
4. склад / закупки  
5. документы + PDF  
6. остальное

## Для переводчика

Источник: `public/locales/ru/*.json`.  
Сдача: те же ключи в `ky` или таблица `key | ru | ky | notes`.  
Пока нет KY — копировать RU. Не оставлять пустые значения.
