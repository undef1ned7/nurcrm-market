## 1. Обзор

Владелец меняет оформление витрины в NurMarket («Редактор сайта»), сервер его хранит. До этой работы страница `/catalog/{slug}` оформление не читала, вид был зашит в код. Теперь она:

- загружает опубликованный вид, а по ссылке `?preview=<token>` — черновик;
- применяет тему (цвета, режим, шрифт, скругление, тени, стиль кнопок);
- строит страницу из блоков в порядке `sections`;
- без ответа сервера показывает прежний вид, без белого экрана.

Основная реализация уже была в рабочем дереве к началу проверки. В этой работе она сверена с ТЗ, исправлены найденные недочёты (раздел 6) и написаны E2E-тесты (раздел 7).

## 2. Загрузка вида (п. 2.1 ТЗ)

Хук: `src/pages/catalog/model/useShowcaseDesign.ts`.

| Поведение | Как сделано |
|---|---|
| Запрос | `GET /main/public/companies/{slug}/showcase/design/`, таймаут 10 с |
| Предпросмотр | `?preview=<token>` из адреса страницы передаётся в запрос. Сверху полоса «Предпросмотр — покупатели этого пока не видят» |
| Неверная или просроченная ссылка | Сервер отказал → показывается опубликованный вид и полоса «Ссылка предпросмотра недействительна или устарела» |
| Нет ответа / ошибка / мусор | Прежний вид. Если документ не похож на оформление (нет `theme`), он не применяется |
| Сервер долго отвечает | Страница ждёт не дольше 2,5 с и открывается в прежнем виде; пришедшее позже оформление применяется без перезагрузки |
| Ошибка отрисовки с оформлением | `DesignBoundary` в `Catalog.tsx` перерисовывает страницу без оформления |
| Кэш | Опубликованный вид хранится в `localStorage` (`showcase_design_{slug}`) и показывается сразу при следующем открытии, затем сверяется с сервером. Черновик не кэшируется |
| Обновление | При возврате на вкладку — повторный запрос, не чаще раза в 15 с |

Публикация видна при следующем открытии или возврате на вкладку. Если сервер или CDN кэшируют ответ, срок кэша должен быть не больше минуты (п. 3.2 приёмки).

### Картинки

Картинки в документе — id из словаря `media` (`header.logo`, `hero.image`, `card.placeholder_image`, `seo.og_image`, `seo.favicon`, а также `theme.background_image`). Адрес берётся из `media[id].urls`; размер подбирается под место (`mediaUrl`), для логотипа и главного блока задан `srcset` с 320 / 640 / 1080 / 1920 — браузер выбирает размер под экран.

## 3. Оформление (п. 2.2 ТЗ)

Модель: `src/pages/catalog/model/showcaseDesign.ts`. Каждое поле ответа проверяется и при ошибке заменяется значением по умолчанию.

| Поле | Как применяется |
|---|---|
| `theme.colors.*` (17 цветов) | CSS-переменные `--sf-*` на корне витрины. Принимаются только hex, `rgb()`, `hsl()` — иначе цвет по умолчанию (защита от внедрения CSS) |
| `theme.mode` | `light`, `dark`, `auto`. Для `dark` и `auto` при светлой палитре строится тёмный вариант; `auto` — по `prefers-color-scheme` устройства |
| `theme.font.family` | Только шрифты из списка редактора. Загружается с Google Fonts с `subset=cyrillic,cyrillic-ext` (ң ө ү) |
| `theme.font.base_size`, `heading_weight` | 13–18 px; 400–900 |
| `theme.radius` | 0–28 px |
| `theme.shadow` | `none` / `soft` / `strong` |
| `theme.button_style` | `filled` / `outline` / `soft` |

Числа вне допустимых границ прижимаются к ним (например, `radius: -50` → 0, `columns.desktop: 99` → 6).

## 4. Блоки страницы (п. 2.3 ТЗ)

| Блок | Компонент | Что поддерживается |
|---|---|---|
| Шапка `header` | `ShowcaseHeader.tsx` | Логотип и высота, название, слоган, `logo_left` / `logo_center`, `sticky`, поиск и его подсказка, текст кнопки корзины, полоса `announcement` (текст, цвета, ссылка) |
| Порядок `sections` | `Catalog.tsx` | Порядок массива, только `enabled: true`. Этап 1: `hero`, `categories`, `products`. Этап 2 тоже есть: `banners`, `promo_blocks`, `new_arrivals`, `on_sale`, `featured`, `text`, `contacts` |
| Главный блок `hero` | `ShowcaseHero.tsx` | `card`, `cover` (картинка на всю ширину, затемнение `overlay` 0–0,8), `split`, `hidden`; заголовок, подзаголовок, `align`, кнопка (без ссылки ведёт к товарам) |
| Категории `categories` | `ShowcaseCategories.tsx` | `chips` / `tiles` / `list` / `hidden`, заголовок, «Все», счётчики, `order`, `hidden` |
| Товары `products` | `Catalog.tsx`, `useShowcaseData.ts` | Заголовок, колонки (desktop / tablet / mobile), `page_size`, `pages` / `load_more` / `infinite`, сортировка по умолчанию и список вариантов, число товаров, скрытие «нет в наличии» и «цена 0» |
| Карточка `card` | `ShowcaseCard.tsx` | 4 шаблона, пропорция и вписывание фото, место цены, картинка-заглушка или текст заглушки, все `show.*`, «новинка» по `new_badge_days`, тексты значка и кнопки, тень, рамка |
| Корзина `cart` | `SideCart.tsx`, `Catalog.tsx` | Боковая панель или страница, поля покупателя (`required` / `optional` / `hidden`), минимальная сумма, самовывоз и доставка (стоимость, «бесплатно от»), текст оплаты, номер WhatsApp, тексты кнопки и благодарности |
| Подвал `footer` | `ShowcaseFooter.tsx` | Адрес, телефоны (`tel:`), часы, соцсети (ник превращается в ссылку), карта, копирайт |
| SEO `seo` | `useShowcaseHead.ts` | `<title>`, `description`, `og:image`, favicon, `noindex` при `indexing: false` и на любом предпросмотре. При уходе со страницы теги возвращаются как были |

Тексты — словари по языкам: берётся `languages.default`, если там пусто — первый непустой (`tx()`).

Без оформления витрина выглядит как раньше (`LEGACY_SECTIONS`, `LEGACY_CARD_VIEW`).

## 5. Вёрстка на телефоне (п. 2.4 ТЗ)

Проверено автотестами на ширине 360, 412 и 414 px для `columns.mobile` = 1, 2 и 3:

- нет прокрутки вбок;
- кнопка корзины, надпись «10 категорий» и карточки не выходят за край экрана;
- колонок ровно столько, сколько в `columns.mobile`.

Прежний вид (без оформления) на 412 px тоже не шире экрана. На настоящем телефоне не проверялось — это остаётся для ручной приёмки.

## 8. Что не покрыто и открытые вопросы

- **Ручная приёмка п. 3.1–3.3** в NurMarket на тестовой компании (`nbs-3`): шесть тем, «Опубликовать», «Отменить изменения» / «Вернуть версию». Автотесты проверяют фронт на подменённых ответах.
- **Настоящий телефон** (п. 2.4) — проверена только эмуляция ширины.
- **`order_channel`** — реализован только WhatsApp; другие значения не обрабатываются.
- **Подборки этапа 2** (`new_arrivals`, `on_sale`, `featured`) запрашивают товары с параметрами `is_new=true`, `on_sale=true`, `pinned=true` — нужно подтвердить, что сервер их понимает.
- **Кэш ответа на сервере или CDN** должен быть не дольше минуты, иначе публикация появится позже (п. 3.2 приёмки).
