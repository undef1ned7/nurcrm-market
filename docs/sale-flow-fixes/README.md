## Порядок работы (рекомендация)

1. **Сначала бэкенд-блокеры** (8, 9, 1, 11) — без них часть фронтовых фиксов бессмысленна (например, №1 без дедупликации на бэке не защищает от двойной продажи).
2. **Параллельно — чистые фронтовые баги без зависимостей** (2, 3, 4, 12) — можно чинить сразу, независимо от бэка.
3. **№7** — тактическое решение (очередь на фронте) можно делать не дожидаясь бэка, но стратегическое (атомарность на бэке) закрывает проблему полностью.
4. **№10** — рефактор типов, делать постепенно, начиная с thunk'ов, которые уже фигурируют в багах 1/5/9.
5. **№6** — не баг в строгом смысле, а уборка мёртвого кода, можно отложить.
