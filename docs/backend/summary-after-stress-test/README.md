# «Сводка» (`/crm/market/summary`): задачи бэкенду после стресс-теста

**Дата:** 06.10.2026
**Экран:** `/crm/market/summary` — выручка, чеки, средний чек, валовая прибыль, график, способы оплаты, последние продажи, лучшие товары, «Заканчивается на складе», блок ABC.
**Код фронта:** `src/pages/market-summary/` (разбор ответов — `model/summaryData.ts`, загрузка — `model/useMarketSummary.ts`).

## Что произошло

«Сводка» прошла стресс-тест: мусор и `null` в ответах, отказ отдельных запросов, кассир без права «Аналитика», 10 нажатий «Обновить» подряд, медленная сеть, быстрая смена периода, период на 10 лет, ширина 360 px. Ошибки фронта исправлены и закрыты тестами (`MarketSummary.regress.test.tsx`, `summaryData.test.ts`, `period.test.ts`).

Что поменялось на фронте и касается API:

| Было | Стало |
|---|---|
| «Заканчивается на складе» скачивал весь каталог (до 100 страниц) раз в 2 минуты и на каждое «Обновить» | один запрос `GET /main/products/list/?stock_type=total&stock_condition=lt&stock_value=6`, повторные нажатия не плодят запросы |
| «к вчера»: сегодня до текущего часа против всего вчерашнего дня | сравнение «на это же время»: `period_end` прошлого периода — вчера в то же время суток |
| Последние продажи: `GET /main/pos/sales/?page_size=8` | `?page_size=24&ordering=-created_at`, открытые корзины (`status=new`) отбрасываются на фронте |
| Кассир без «Аналитики» получал 403 от аналитики и нули | аналитика для него не запрашивается; видит последние продажи и остатки |
| Свой период без конца в прошлом обновлялся каждые 20 секунд | не обновляется: прошлые дни не меняются |
