# Маркет — Чек: стабильный id позиции для merge eKassa ↔ items

**Эндпоинты:**
- `GET /main/sales/json/{sale_id}/receipt/`
- фискальный блок `ekassa_fiscal.fields` / `ekassa.fields` (тег **1059** — массив позиций)

**Статус:** ⚠️ Нужен бэкенд. Фронт мержит по `item_id` / `line_id` / `sale_item_id` / `id`, иначе по **индексу**, иначе по имени+qty (`receiptItems.ts`).

---

## 1. Проблема

Фронт печатает построчные скидки маркета поверх позиций eKassa (тег 1059). Сопоставление без стабильного id:

1. по индексу массива (если длины совпадают);
2. иначе по `name + qty`.

Если в чеке **два одинаковых товара** с разными скидками и порядок 1059 ≠ порядок `items[]`, скидки могут прилипнуть не к тем строкам. Имя+qty не различает дубликаты.

## 2. Что нужно от бэка

### В `items[]` receipt JSON

У каждой строки — стабильный id продажи/корзины:

```json
{
  "item_id": "3f2c…",
  "name": "Кола",
  "qty": 1,
  "unit_price": "50.00",
  "line_discount": "5.00",
  "line_total": "45.00"
}
```

Допустимые имена (фронт читает все): `item_id`, `line_id`, `sale_item_id`, `id` (строки чека, не `product_id`).

**Не** использовать как уникальный ключ: `product_id`, штрихкод, только имя.

### В eKassa fields → 1059

В каждом элементе массива 1059 — **тот же** id:

```json
{
  "1030": "Кола",
  "1023": 1,
  "1076": 5000,
  "1043": 4500,
  "item_id": "3f2c…"
}
```

Если id нельзя положить в официальный тег ФФД — допустимо vendor-расширение на объекте позиции рядом с 1030/1023/…, главное — одно и то же значение, что в `items[]`.

## 3. Поведение фронта

Приоритет match:

1. совпадение `item_id` / `line_id` / …  
2. индекс (равные длины массивов)  
3. `name + qty` (только если длины разные)

При name+qty или если Σ построчных скидок > order-level discount — `console.warn` (печать не блокируется).

## 4. Приёмка

| # | Данные | Ожидание |
|---|--------|----------|
| 1 | Две «Кола», скидки 5 и 20, порядок в 1059 обратный `items`, оба с `item_id` | скидки на бумаге соответствуют id |
| 2 | Без id, одинаковая длина | merge по индексу |
| 3 | Без id, разная длина | fallback name+qty + warn в консоли |
